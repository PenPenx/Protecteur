# Carnet du Protecteur

Application de jeu sur téléphone pour *Les Souvenirs du Protecteur* (jeu de rôle en solitaire).
Tout tient dans `carnet-du-protecteur.html`, publié en page privée sur claude.ai.

- **Voyage** : Horloge jour/nuit, carte hexagonale (départ en E13), biomes, rencontres, collecte.
- **Protecteur** : Attributs, Honneur, Inspiration, pièces, inventaire (Endurance × 6), sorts.
- **Dés** : test de Courage (Faim, Bouclier, Stimulant), dés, paquet de 52 cartes, oracle, affrontements.
- **Tables** : tables du livre, générateurs (village, comptoir, habitant, Ruine, mission, écran des langues anciennes), encyclopédie.
- **Journal** : journal de voyage, souvenirs et Ferveur, Salle des Souvenirs, missions, sauvegarde.

Les faces de dé et les enseignes illisibles sur les photos sont apprises en jeu : au premier tirage inconnu, l'application demande le résultat lu dans le livre et le retient.
